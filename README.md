# Hachi: A Dog's Tale 

## Overview {#overview}

**Hachi: A Dog's Tale** is a *heartwarming* 2009 drama directed by Lasse Hallström and starring Richard Gere. It is an American remake of the 1987 Japanese film *Hachikō Monogatari*.[^1]

[^1]: Both films are based on the true story of Hachikō, an Akita dog from Japan.
